# 統測／二技 國文英文考題分析

- 統測（四技二專）共同科目：<https://bgjd315-cloud.github.io/tvee-common/>（110–115 學年度）
- 二技統一入學測驗 共同科目：<https://bgjd315-cloud.github.io/tvee-common/erji/>（108–115 學年度）

國文、英文是各群類共用的試卷。網站依測驗中心公告的歷屆試題，整理各題型的出題趨勢、逐題截圖與解析，並提供練習模式、錯題本與讀書計畫。

- 題目截圖取自技專校院入學測驗中心公告的試題本，答案為公告答案。
- 解析由 Claude 撰寫，使用前請任課老師覆核。
- 錯題本與讀書計畫進度存在各自裝置的瀏覽器中。

## 資料來源與更新

題目、章節分類與解析和護理類考題分析網站共用（<https://github.com/bgjd315-cloud/tvee-nursing> 的 `source/`）。每年新增學年度時，先更新護理類的資料，再把 `source/build_common.py` 放到護理類 `source/` 底下的 `common/` 資料夾執行，產生的 `site_common/` 內容複製到本專案根目錄後推送。
